# VC4 VC4Tile M5 Codex Contract

Codex is a narrow mechanical repair tool. It may patch only obvious compile/build/API/path integration failures after a deterministic gate has produced an exact error log.

Allowed repairs include matching generated code to an existing API, adding a missing include/declaration for an existing type/function, fixing tiny CMake/lit/PATH/support-runner plumbing, or cleaning stale build-tree test artifacts after source restoration.

Codex must decline and print exactly `VC4_CODEX_NEEDS_GPT` when the repair requires semantic design for VC4Tile surface ops, copy planning, SSAVC4 VDR/VCD semantics, scheduling, QASM, launch ABI, runtime policy, hardware behavior, expected-result/oracle changes, feature ownership, verifier semantics, or broad refactoring.

Codex must not implement producer lowering, direct `vc4tile -> vc4`, executable sub-32 precision, dummy verifier comments, reference rewrites, fake result paths, or `.vc4_auto` edits. Mechanical repair budget is three attempts per category for M5 implementation slices.
