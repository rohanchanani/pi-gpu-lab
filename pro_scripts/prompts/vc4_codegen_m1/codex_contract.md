# Codex Mechanical-Fix Contract for VC4 Codegen Milestone 1

Codex is a constrained mechanical fixer. The autorun script may dispatch Codex only after deterministic failure classification.

## Codex may fix

Codex may fix:

- CMake wiring mistakes
- missing include directives
- namespace qualification errors
- MLIR API spelling mismatches
- simple compile errors in new codegen files
- simple C syntax errors in generated launcher tests
- trivial FileCheck typo only when the classifier explicitly allows test edits

## Codex must not fix

Codex must not attempt to fix:

- qasm syntax or semantics
- branch offset or label semantics
- launch ABI layout semantics
- uniform packing order
- public launcher API design
- hardware result mismatches
- hardware timeouts/deadlocks
- VC4 verifier semantics
- scheduler/runtime behavior
- reference bundles
- expected oracle files
- catalog entries

## Attempt limit

Codex gets at most one mechanical attempt per classified failure cycle unless the human explicitly overrides the limit.

If Codex fails, changes forbidden paths, or produces a broader patch than requested, the autorun script must reject or restore the patch and route the failure back to GPT Pro.

## Prompt source

Codex prompts are generated by the deterministic autorun script, not by GPT Pro. GPT Pro may include a `codex_hint` field in `response.json`, but the script decides whether Codex is eligible and what prompt Codex receives.
